A high-performance personal engineering portfolio and credentials vault built with Next.js 16 App Router, TypeScript, Framer Motion, and Tailwind CSS v4. Features verified Cisco Networking Academy certifications, Credly badge integrations, and full-stack project architecture case studies.

🌐 **Live Website:** [https://subharup.com](https://subharup.com)

---

## ✨ Key Features

- **High-Performance Architecture:** Zero-runtime client overhead with Next.js App Router and static edge prerendering.
- **Adaptive Light/Dark Theme:** Tailwind v4 manual dark variant mapping (`@variant dark`) with WCAG-compliant contrast across all pages.
- **Credentials Vault:** Verified Cisco Networking Academy accreditations, Credly badge integrations, and inline PDF/image document previews.
- **Project Case Studies:** Architectural breakdowns for edge applications, subnet calculators, and network telemetry utilities.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript (Strict Mode)
- **Styling:** Tailwind CSS v4, CSS Custom Properties
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Hosting & Edge Deployment:** Cloudflare Pages
